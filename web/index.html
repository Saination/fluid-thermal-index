The cp-invariance theorem

All four sub-metrics scale linearly with the fluid's specific heat capacity (cₚ). When normalised for comparison, cₚ cancels exactly — so the source ranking below is mathematically identical no matter which fluid you pick. Try switching fluids and watch the ranking order stay the same.
